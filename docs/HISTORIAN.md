## ข้อจำกัดที่ควรบันทึกเพิ่ม

**ข้อจำกัด 4 ข้อเดิมท้าย `geo.js` ยืนยันแล้วว่ายังถูกต้องทั้งหมด:**
1. จิ่วเฉวียน/ตุนหวงอยู่นอกแผนที่ ✓ — ไม่มีใน `places.js` จริง เมืองตะวันตกสุดคือจางเย่ที่ x=24 · และ **ชื่อสองเมืองนี้ยังปรากฏในเนื้อ beat `c3-05`** จึงเป็นข้อจำกัดที่ยังมีผลอยู่
2. เซียงเพ้งใส่พิกัดประมาณ ✓ — `map:null, chk:true` ยังอยู่ครบ
3. ซีหลิงใช้หมุดเดียวกับ Yi Ling ✓ — `map:"Yi Ling / Xi Ling"` และไม่มี entry `yiling` แยก
4. หยูซวีวางฝั่งเหนือแม่น้ำ ✓ — `ruxu [1329,879]` ตกในภูมิภาค `huainan_s` จริง ผลคือช่วง 228–234 ลูกศรง่อ (`c3-10`) ออกจากจุดที่ระบายสีวุ่ยอยู่

**ข้อจำกัดที่ควรเพิ่มอีก 7 ข้อ:**

1. **polygon 20 คู่ซ้อนทับกัน และคู่ที่เจ้าของต่างกันจะเห็นสีผิดบนจอ**
   `js/strategic.js` วาดทุกภูมิภาคเรียงกันใน `#L-regions` ตัวที่นิยามทีหลังจึงทับตัวก่อนหน้าจนมิด
   คู่ที่ "เจ้าของต่างกัน + พื้นที่ทับใหญ่ + กินเวลานาน" เรียงตามความรุนแรง:

   | คู่ | พื้นที่ทับ | ช่วงที่เจ้าของต่างกัน | ผลบนจอ |
   |---|---|---|---|
   | `huainan_s ∩ yangzhou` | ~5,750 px² | 228–234 และ 275–276 | แถบสีง่อกินเข้าไปในเขตวุ่ย/ฮั่นแถวหับป๋า-หยูซวี |
   | `huainan_n ∩ huainan_s` | ~1,900 px² | 234–263 (29 ปี) | สีง่อกัดเข้าเขตโซ่วชุนของวุ่ย |
   | `guanzhong ∩ hedong` | ~925 px² | 229–257 (28 ปี) | **ครอบหมุดท่าข้ามผู่ปั่นพอดี** — จุดที่เนื้อเรื่องเน้นว่าเป็น "บานที่คนมักลืม" ของฮั่น กลับถูกระบายเป็นสีวุ่ย |
   | `yuzhou ∩ huainan_n` | ~6,900 px² | 262–263 | |
   | `yuzhou ∩ jingzhou_n` | ~3,275 px² | 262–263 | |
   | `longyou ∩ guanzhong` | ~1,450 px² | 228–229 | ช่วงไคลแม็กซ์ภาคหนึ่งพอดี |
   | `hedong ∩ sili` | ~2,875 px² | 255–257 | |
   | `longyou ∩ liangzhou` | ~375 px² | 228–231 | |
   | `hanzhong ∩ shangyong` | ~50 px² | 228–263 (35 ปี) | เล็กแต่ยาวที่สุด |

   (อีก 11 คู่ทับกันแต่เจ้าของตรงกันตลอดเรื่อง จึงมองไม่เห็น)
   หมายเหตุ: CSS ใช้ `stroke-width:34` เพื่อปิดช่องว่างระหว่างเขตอยู่แล้ว การซ้อนระดับขอบจึงเป็นของที่ตั้งใจ
   แต่เก้าคู่ข้างบนซ้อนลึกเกินความหนาขอบ

2. **`puban` ตกอยู่ในสองภูมิภาคพร้อมกัน (`guanzhong` + `hedong`)**
   ละเมิด invariant ที่เขียนไว้ในหัวไฟล์ `geo.js` เองบรรทัด 7: *"ทุกสถานที่สำคัญต้องตกอยู่ในภูมิภาคเดียว ไม่ซ้อน ไม่หลุด"*
   เป็นสถานที่เดียวในบรรดา 39 จุดที่ timeline เรียกใช้ที่ละเมิดข้อนี้

3. **สถานที่ที่หลุดออกนอกทุกภูมิภาค** — `luogu` (หุบเขาลั่วกู่) · `lueyang` · `xiabian` · `bohai` · `guangling`
   และที่ตกสองเขตพร้อมกัน — `jincheng` (longyou+liangzhou) · `liyang` · `baima` (jizhou+yanzhou)
   ทั้งหมดยังไม่ถูกเรียกใช้ใน marker จึงยังไม่กระทบภาพ แต่ถ้าเฟสหลังหยิบมาใช้จะเจอปัญหาทันที

4. **ไม่มีภูมิภาค "ยงจิ๋ว" บนแผนที่** ทั้งที่ต้นฉบับเอ่ยถึง 9 ครั้ง — ถูกแทนด้วย `longyou` + `guanzhong` รวมกัน

5. **"ประตูสี่บานของกวนจง" แสดงได้แค่สามบาน** — beat `c2-05` มีลูกศรถงกวน/อู่กวน/ผู่ปั่น แต่ไม่มีเซียวกวน
   ทั้งที่ `places.js` นิยาม `xiaoguan` ไว้แล้ว (และ **เซียวกวนอยู่ในเขต `longyou` ไม่ใช่ `guanzhong`** ซึ่งอธิบายว่าทำไมถึงตกหล่น)

6. **อี๋เต้ากับซีหลิงห่างกันเพียง ~20px** (`[806,1019]` กับ `[816,1003]`) — ทั้งสองถูกใช้ใน `xiling272.js`
   ในระดับซูมของแผนที่ยุทธศาสตร์ หมุดสองอันนี้จะทับกัน (ปัญหาแบบเดียวกับข้อจำกัดเดิมข้อ 3)

7. **การเปลี่ยนมือระดับต่ำกว่าภูมิภาคแสดงไม่ได้** — กรณีที่เจอในเรื่องคือง่อเลาะกินหวยหนำ 258–263
   และซีหลิงแปรพักตร์เข้าฮั่นชั่วคราวในปี 272 (แสดงได้เฉพาะเป็น marker ไม่ใช่การเปลี่ยนสีพื้นที่)

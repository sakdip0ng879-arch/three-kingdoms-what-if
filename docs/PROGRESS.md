## 2026-07-26 · เฟส 6 · Design pass + Historian ตรวจ

**จากที่ผู้ใช้ทัก 3 เรื่อง**
1. เส้นในสมรภูมิไม่มีคำอธิบาย → เพิ่มหัวข้อ "อ่านแผนที่" **โชว์เฉพาะชนิดเส้นที่ศึกนั้นมีจริง**
2. แผนที่ใหญ่ซูมแล้วไม่บอกว่าดูอะไร → ป้ายบอกตำแหน่ง + ตีกรอบประเน้นเขต
   **หาเองจากกล้อง+หมุดของฉาก ไม่ต้องแก้ข้อมูล 71 ฉาก**
3. โหมด C (สำรวจ) ยังไม่ครบ → **ลากแถบเวลาไล่ดูได้แล้ว** (ระหว่างลากกล้องสั้นลงเหลือ 320ms และไม่เล่นลูกศร)

**สิ่งที่ dataviz skill จับได้ ซึ่งไม่เคยตรวจมาก่อน**
รันตัววัดสีจริงแทนการเดา:
- **สีระบายพื้นที่สามฝ่ายผ่านหมด** รวมถึงการแยกสีสำหรับคนตาบอดสี — คู่ที่แย่ที่สุด (แดง↔น้ำเงิน) ได้ ΔE 17.3 เทียบเกณฑ์ 8
- **แต่เอาไปใช้เป็นตัวอักษรไม่ผ่าน** — น้ำเงินวุ่ย 2.87:1 · แดงง่อ 3.44:1 ต่ำกว่าเกณฑ์ 4.5:1
  → แยก `text:` เป็นเวอร์ชันสว่างกว่า และเปลี่ยน HUD ให้ใช้จุดสีข้างชื่อแทนการระบายตัวหนังสือ

**Design pass อื่น**
- คืนสีแผนที่พื้น + ปุ่มสลับ 3 ระดับ (จาง/กลาง/ชัด) จำค่าที่เลือก — เดิมฟอกทิ้งเพื่อช่วยตัวหนังสือ ซึ่งแก้ผิดจุด
- **สีถมข้ามอ่าวโป๋ไห่** ทำให้อิวจิ๋วกับเลียวตั๋งดูติดกัน ทั้งที่มีทะเลคั่น (เหตุผลที่สุมาอี้ต้องอ้อมสี่พันลี้ปี 238) → หุบขอบเข้า

**บั๊กที่เจอระหว่างทำ** — ป้ายบอกตำแหน่งขึ้น "ทั้งแผ่นดิน" ทุกฉาก
เพราะตัดสินจาก viewBox จริงบนจอ แต่ `fitBox` ขยายกรอบให้พอดีสัดส่วนจอ
จอ 2454×784 ทำให้กรอบที่ตั้งใจซูม 340 บานเป็น 1535 → เปลี่ยนไปตัดสินจากกรอบที่เขียนไว้ในข้อมูลแทน

**ผู้ใช้เจอ** ก้อนดำใหญ่คลุมครึ่งจอ และวงกลมสีส้มไหลกระจายออกนอกแผนที่

**สาเหตุ — สองอย่าง ทั้งคู่ DOM ถูกหมด ผิดตอนเรนเดอร์เท่านั้น**

1. **ก้อนดำ** — ตอนคำนวณเส้นทางเดินทัพ สร้าง `<path>` ไว้วัดระยะแล้วใส่ลง DOM

   `transform-box:fill-box` คำว่า center หมายถึงกึ่งกลางของ **viewport ทั้งผืน**
   ไม่ใช่ของรูปนั้น พอ `scale()` รูปจึงถูกเหวี่ยงออกไปเรื่อย ๆ
   → บั๊กเดียวกันมีที่วงแหวนปะทะบนแผนที่ใหญ่ และวงล้อมเมืองด้วย แก้พร้อมกันทั้งสามจุด

**สิ่งที่สร้างเพิ่ม: `tools/selfcheck.js`**
ตรวจสิ่งที่การอ่าน DOM มองไม่เห็น 4 อย่าง — path ที่ไม่มีทั้ง fill และ class ·
animation ที่ลืม transform-box · อะไรที่วาดหลุดนอกกรอบ · สัญลักษณ์ทับกัน

**ตัวตรวจเองก็มีบั๊ก — เจอเพราะจงใจใส่บั๊กกลับเข้าไปทดสอบ**

| 2 | แก้เป็น `getBoundingClientRect()` และดักเฉพาะ path ที่ไม่มีทั้ง fill และ class → แต่จับบั๊กก้อนดำไม่ได้ เพราะกฎ CSS เหมารวมที่เพิ่งใส่ไปช่วยกลบไว้ |
| 3 | เปลี่ยนเกณฑ์เป็น "ผู้เขียนสั่งหรือยัง" ไม่ใช่ "ตอนนี้ผิดหรือยัง" → จับได้ครบ |

**ผู้ใช้ทักว่า** ที่เกเต๋งวุ่ยแพ้ แต่ลูกศรวุ่ยกลับถอยออกมาจากเทียนซุย ซึ่งดูไม่เข้าท่า

**ตรวจทั้งเรื่องก่อนแก้** — เขียนสคริปต์ audit ไล่ลูกศรทั้ง 40 อัน เทียบทิศทางกับเจ้าของเขต ณ ปีนั้น

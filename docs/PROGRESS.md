## 2026-07-25 · เฟส 3.1 · แก้ทิศทางลูกศรเดินทัพ (จากที่ผู้ใช้ทัก)

**ผู้ใช้ทักว่า** ที่เกเต๋งวุ่ยแพ้ แต่ลูกศรวุ่ยกลับถอยออกมาจากเทียนซุย ซึ่งดูไม่เข้าท่า

**สาเหตุ** — เส้นทาง `longyou_chencang` เริ่มที่พิกัด (356,607) ซึ่งเป็น**พิกัดหมุดเทียนซุยเป๊ะ ๆ**
พอลากลูกศรสีวุ่ยจากจุดนั้น มันเลยดูเหมือนวุ่ยโผล่ออกจากเมืองที่เพิ่งแปรพักตร์ไปอยู่กับฮั่น
รากปัญหาที่ลึกกว่านั้น: **ระบบลูกศรไม่มีหัวลูกศร และไม่มีความต่างระหว่างบุกกับถอย** เลยอ่านทิศไม่ออกทั้งเรื่อง

**ตรวจทั้งเรื่องก่อนแก้** — เขียนสคริปต์ audit ไล่ลูกศรทั้ง 40 อัน เทียบทิศทางกับเจ้าของเขต ณ ปีนั้น
เจอน่าสงสัย 3 อัน ตรวจรายตัวแล้วเป็นของจริง 2:

| ฉาก | ปัญหา | แก้ |
|---|---|---|
| c1-05 | ฮั่นออกจากกิสานซึ่งยังเป็นเขตวุ่ย | **ไม่ผิด** — นั่นคือการบุก (false positive ของ heuristic) |
| c1-06 | ถอยแต่วาดเหมือนบุก + เริ่มทับหมุดเทียนซุย | ขยับต้นทางเป็น (378,616) + ใส่ `retreat:true` |
| c7-03 | จางทีข้ามแม่น้ำมาตี แต่ลูกศรวิ่งกลับทิศ | ใส่ `reverse:true` |

**แก้ที่ระบบ**
- ทุกลูกศรมี **หัวลูกศร** เสมอ (`<marker>` + `fill:context-stroke` ได้สีตามเส้นโดยไม่ต้องสร้างต่อฝ่าย
  และ `markerUnits` ปริยายคือ strokeWidth ขนาดจึงคงที่บนจอตามเส้นไปเอง)
- เพิ่มสองธงบน marker ชนิด arrow — **แยกกันเด็ดขาด**:
  - `reverse:true` = ทิศทาง วิ่งย้อนเส้นทาง
  - `retreat:true` = ความหมาย เป็นการถอย มีผลแค่หน้าตา (เส้นจาง หน่วยเป็นโครงกลวง)

**บั๊กที่ผมทำเองระหว่างแก้** — ตอนแรกให้ `retreat` ลาก `reverse` ไปด้วย คิดว่าถอย = ย้อนทาง
แต่กุยห้วยถอย **"ไปยัง"** ตันฉอง ซึ่งเป็นทิศเดียวกับที่ route วางไว้อยู่แล้ว การย้อนทางเลยทำให้เขาวิ่งกลับผิดทาง
→ แยกสองธงออกจากกัน

**ผลตรวจหลังแก้** (ทดสอบด้วย `animate=false` ให้ settle ทำงานทันที ไม่ต้องพึ่ง rAF)

|---|---|---|
| c1-06 | วุ่ย [ถอย] | ตันฉอง ✓ |
| c7-03 | ง่อ [ย้อน] | หยูซวี ✓ |

**บทเรียนเรื่องการทดสอบ** — `requestAnimationFrame` **ไม่ทำงานตอนหน้าต่างเบราว์เซอร์ถูกซ่อน**
ทำให้ tween ทุกตัวค้างที่เฟรมแรก ตอนแรกนึกว่าเป็นบั๊ก เสียเวลาไล่อยู่พักหนึ่ง

**ระบบวางป้ายชื่อ (labeler.js)**
ปัญหา "ชื่อทับกัน" แก้ด้วยอัลกอริทึม ไม่ใช่ขยับพิกัดทีละอัน — ไม่งั้นจะแก้ไม่รู้จบ
1. จัดอันดับ นครหลวง=1 เมืองใหญ่=2 เมือง=3 ด่าน/ภูเขา=4
2. LOD ตามซูม: กว้าง>1100 โชว์อันดับ 1 · >650 ถึง 2 · >330 ถึง 3 · ใกล้กว่านั้นครบ 4
3. แต่ละป้ายลอง **8 ตำแหน่งรอบหมุด** เอาอันแรกที่กล่องไม่ชนใคร ไม่มีที่ว่าง = ซ่อน
4. เพดาน 26 ป้ายกันจอรก · สถานที่ที่ฉากนั้นพูดถึงถูก force ให้โผล่เสมอ (สีทอง)

วัดความกว้างข้อความด้วย `canvas.measureText` จริง ไม่ใช่เดาจากจำนวนตัวอักษร
— สำคัญกับภาษาไทยเพราะสระบน-ล่างไม่กินความกว้าง

**บั๊กที่เจอและแก้ (ทั้งหมดหาเจอด้วยการวัด ไม่ใช่เดา)**
1. **สเกลเพี้ยนครึ่งหนึ่ง** — `preserveAspectRatio="meet"` ย่อ/ขยายตาม**ด้านที่คับกว่า**
   viewBox สัดส่วน 1:1.18 (ตามภาพ) แต่กล่องบนจอ 1:0.53 → สเกลจริงถูกจำกัดด้วยความสูง
   `mu = vb.w / screenW` จึงผิด ตัวอักษรออกมาเล็กกว่าที่สั่งเท่าตัว
   **แก้:** บังคับสัดส่วน viewBox ให้ตรงกับกล่องเสมอ (`fitBox`) + คำนวณสเกลด้วย `min()`
   ผลพลอยได้: กล้องไปตรงตำแหน่งที่สั่งจริง ๆ และ resize หน้าต่างแล้วไม่เพี้ยน
2. **ฮาโลรอบตัวอักษรหนาไป** — `stroke-width` 0.30 เท่าของ font ทำให้สระไทยเชื่อมกันเป็นก้อนดำ ลดเหลือ 0.17
3. **ป้ายหมุดกับสัญลักษณ์กองทัพขนาดไม่คงที่** — ตั้ง font-size เป็นหน่วยแผนที่ พอซูมแล้วบวมตาม
   **แก้:** แยก `<g>` ชั้นนอกรับ translate ชั้นในรับ scale แล้วปรับ scale ทุกครั้งที่ relayout
4. **HUD ตัวเลขทับแท่งกราฟ** — เดิมใช้ `margin-top:-20px` แก้เป็น flex สองแถวจริง ๆ
5. แผนที่พื้นยังเข้มไป ชื่ออังกฤษที่พิมพ์ติดมาแย่งอ่านกับชื่อไทย → เพิ่มการลดสีเป็น `saturate(.18) brightness(1.30) contrast(.72)`

**การตรวจสอบ (ไม่ได้เชื่อสายตาอย่างเดียว)**
เขียนสคริปต์ตรวจอัตโนมัติด้วย `SVGGeometryElement.isPointInFill()` — เช็กว่าสถานที่สำคัญ 44 แห่ง
ตกอยู่ในภูมิภาคที่ควรอยู่จริงไหม

| รอบ | ผิด | หมายเหตุ |
|---|---|---|
| 1 | 11 / 45 | ตันฉองคาบสองภูมิภาค · อู่กวน อันติ้ง จางเย่ เป๊กเต้เสีย เหอเน่ย์ หลุดออกนอกทุกภูมิภาค · หับป๋ากับสือถิงคาบสองฝ่าย |
| 2 | **0 / 44** | แก้ polygon แล้วผ่านหมด |

เหลือ 4 จุดที่ไม่อยู่ในภูมิภาคใดและ 4 จุดที่คาบสองภูมิภาค — **ตรวจแล้วว่าถูกต้องตามธรรมชาติ**
เพราะทั้งหมดเป็นท่าข้ามแม่น้ำหรือเมืองชายแดน (ผู่ปั่น, กิมเสีย, หลี่หยาง, ไป๋หม่า, ด่านลั่วกู่)

**ปัญหาที่เจอและแก้แล้ว**
1. `Element.append()` คืน `undefined` ไม่ใช่ node ที่เพิ่ง append — โค้ด `x.append(mk('title')).textContent=...` จะพัง แก้เป็นสองบรรทัด
2. polygon เดิมเป็น "ก้อนกลม ๆ มีช่องว่างขาวคั่น" ดูไม่เหมือนดินแดน
   → แก้ด้วย **stroke สีเดียวกับ fill หนา 34px** = ขยายรูปออกด้านละ 17px ปิดช่องว่างโดยไม่ต้องแก้พิกัดสักตัว และมุมมนขึ้นดูเป็นธรรมชาติ
3. stroke ทับ fill ที่โปร่งแสงทำให้เกิดขอบเข้มรอบรูป → ย้าย opacity ไปไว้ที่ `<g>` แทนที่จะอยู่บน path
4. เพิ่มภูมิภาค `shangyong` ปิดช่องว่างระหว่างอู่กวนกับเกงจิ๋วเหนือ

**ข้อจำกัดที่บันทึกไว้ (ยกไปตรวจในเฟส 6)**
- แผนที่ตัดขอบตะวันตกที่จางเย่ → **ไม่มีจิ่วเฉวียนและตุนหวง** ที่ภาคสามเอ่ยถึง `liangzhou` จึงแทนระเบียงเหอซีแบบย่อ
- **เซียงเพ้ง** (เลียวตั๋ง) ไม่มีป้ายบนแผนที่ ใส่พิกัดประมาณ
- **ซีหลิง** ใช้หมุดเดียวกับ Yi Ling (เมืองเดียวกัน คนละชื่อยุค) — ยืนยันจากแผนที่ที่พิมพ์ "Yi Ling / Xi Ling" ซ้อนกัน
- 13 จุดติดธง `chk:true` (วงแดงในภาพ) = พิกัดยังเป็นการประมาณ ลากแก้ได้ใน calibrate.html

# สามก๊ก What If — ถ้าการบุกเหนือครั้งแรกของขงเบ้งสำเร็จ

นิยายทางเลือกประวัติศาสตร์ ค.ศ. 228–276 อ่านคู่กับแผนที่ที่เดินตามเนื้อเรื่องไปด้วย
เลื่อนอ่านทางขวา แผนที่ทางซ้ายจะขยับตาม และกดเข้าไปดูสมรภูมิใหญ่ 8 ศึกแบบเจาะลึกได้

**จุดแยกของเอกภพนี้มีจุดเดียว** — คืนก่อนศึกเกเต๋ง ขงเบ้งเลือกฟังคำเตือนสุดท้ายที่เล่าปี่
ฝากไว้เรื่องม้าเจ๊ก ที่เหลือทั้งเรื่องคือผลลูกโซ่จากคืนนั้น

ทุกฉากมีป้ายบอกว่า **อิงประวัติศาสตร์จริง · จริงผสมแต่ง · แต่งขึ้น** กดที่ป้ายเพื่อดูว่า
ส่วนไหนมีบันทึกและส่วนไหนแต่งเติม เกณฑ์การติดป้ายอยู่ใน `docs/DECISIONS.md` §6.6

## เปิดยังไง

ดับเบิลคลิก `index.html` ได้เลย ไม่ต้องติดตั้งอะไร ไม่ต้องรัน server
(ทั้งโปรเจกต์เป็น HTML/CSS/JS ล้วน ไม่มี build step ไม่มี dependency)

## โครงไฟล์

```
index.html          หน้าเดียวจบ
css/ js/            engine — เขียนครั้งเดียว แทบไม่แตะอีก
data/               เนื้อหาทั้งหมด แก้ที่นี่ ไม่ต้องแตะโค้ด
  _part1..3.js      ต้นฉบับ 71 ฉาก  →  timeline.js (สร้างอัตโนมัติ ห้ามแก้มือ)
  geo.js            รูปภูมิภาคที่ลากด้วยมือ  →  geo_fill.js (สร้างอัตโนมัติ)
  battles/          8 สมรภูมิ
tools/              ตัวสร้างและตัวตรวจ (ดู docs/DECISIONS.md §8.5)
docs/               กฎที่ล็อกไว้ · บันทึกการทำงาน · ผลตรวจความถูกต้องทางประวัติศาสตร์
```

## เครื่องมือ

```
node tools\build_timeline.js     data\_part*.js  →  data\timeline.js
node tools\build_geo.js          geo.js + landmask  →  geo_fill.js
node tools\check_battle.js       ตรวจข้อมูลสมรภูมิ
node tools\check_fact.js         ตรวจป้ายจริง/แต่งว่าขัดกับเกณฑ์ไหม
tools\shot.ps1 c1-05             ถ่ายภาพหน้าจอจริงของฉากที่ระบุ
```
